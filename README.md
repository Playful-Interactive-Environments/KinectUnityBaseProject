# Touch-Interaction-for-Augmented-Reality-Sandboxes #

## Keyboard Layout ##

(Default) F1 : Marker-based Calibration¹

¹ Place the markers ID-wise (0, 1, 2, 3) clockwise from bottom-left over top-left, top-right to bottom-right at the corners of the projection area on the sandbox surface.
